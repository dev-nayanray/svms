# SEO Configuration

This document describes the SEO configuration system for the Euroscope SVMS.

> **Live, interactive version**: `/admin/system/seo` in the admin panel.

## Architecture

### robots.txt

Auto-generated by `app/robots.ts` using the SEO config from
`SystemSetting`. The robots.txt file:

- **Always blocks**: `/admin`, `/admin/*`, `/employee`, `/employee/*`,
  `/student`, `/student/*`, `/api`, `/api/*`.
- **Conditionally blocks**: `/login`, `/register` (blocked by default,
  can be allowed via the `indexPrivateRoutes` config flag).
- **Includes**: sitemap URL + host directive.

### sitemap.xml

Auto-generated by `app/sitemap.ts` from the live database.

**Included routes**:
- `/` (homepage)
- `/study-in-europe`
- `/universities` + `/universities/[slug]` (dynamic, from DB)
- `/courses` + `/courses/[slug]` (dynamic, from DB)
- `/features`, `/how-it-works`, `/about`, `/resources`, `/contact`
- `/login`, `/register`

**Excluded by design**:
- `/admin/*`, `/employee/*`, `/student/*` — private data behind authentication.
- `/api/*` — not user-facing.

### Structured data (JSON-LD)

`app/layout.tsx` emits an `EducationalOrganization` schema in the root
layout. This helps search engines understand that Euroscope is an
educational organization.

```json
{
  "@context": "https://schema.org",
  "@type": "EducationalOrganization",
  "name": "Euroscope",
  "url": "https://your-domain.com",
  "description": "...",
  "slogan": "Study in Europe. Start Your Future.",
  "knowsAbout": [
    "European university admissions",
    "Student visa preparation",
    "Study abroad Europe"
  ]
}
```

No fake reviews, ratings, or partner organizations are emitted.

## Configuration keys

All keys are stored in `SystemSetting` (JSON-valued). Update via
`/admin/system/seo` (admin-only).

| Key | Default | Purpose |
|-----|---------|---------|
| `seo.siteName` | `Euroscope` | Site name shown in metadata. |
| `seo.titleTemplate` | `%s \| Euroscope` | Title template for sub-pages. |
| `seo.metaDescription` | `Euroscope — Study in Europe...` | Default meta description. |
| `seo.locale` | `en_US` | OpenGraph locale. |
| `seo.language` | `en` | HTML lang attribute. |
| `seo.defaultOgImage` | `/euroscope-logo-full.png` | Default OpenGraph image. |
| `seo.defaultTwitterImage` | `/euroscope-logo-full.png` | Default Twitter card image. |
| `seo.canonicalBase` | `NEXT_PUBLIC_APP_URL` | Canonical URL base. |
| `seo.indexPrivateRoutes` | `false` | Allow indexing of `/login` and `/register`. |

## Private route protection

The following routes are ALWAYS blocked from indexing (regardless of
the `indexPrivateRoutes` setting):

- `/admin`, `/admin/*`
- `/employee`, `/employee/*`
- `/student`, `/student/*`
- `/api`, `/api/*`

These are also protected by:
- **Authentication** (NextAuth v5 JWT check in `proxy.ts` middleware).
- **RBAC** (role-based access control in server components + API routes).
- **Security headers** (CSP, X-Frame-Options: DENY).

## Technical audit

The admin SEO page (`/admin/system/seo`) runs a technical audit covering:

- Site name configured
- Meta description length (≥120 chars recommended)
- Canonical base URL is HTTPS
- robots.txt route exists
- sitemap.xml route exists + dynamic entry counts
- HTTPS canonical URL
- Private routes blocked
- OpenGraph image configured
- Twitter card image configured
- Locale configured
- Structured data present
- `NEXT_PUBLIC_APP_URL` matches canonical base

Each check returns `PASS` / `WARN` / `FAIL` with a detail string.

## Production checklist

- [ ] `NEXT_PUBLIC_APP_URL` set to `https://your-domain.com`
- [ ] `seo.canonicalBase` matches `NEXT_PUBLIC_APP_URL`
- [ ] Default OpenGraph image is at least 1200×630 px
- [ ] Default Twitter card image is at least 1200×628 px
- [ ] Meta description is at least 120 characters
- [ ] All private routes are blocked in robots.txt
- [ ] Sitemap is accessible at `/sitemap.xml`
- [ ] Structured data validates via Schema.org validator
