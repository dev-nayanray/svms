# Getting Started — Euroscope Admin Panel

This guide helps a new administrator get up and running in 15 minutes.

## 1. First Login

1. Go to `your-domain.com/login`
2. Enter your email and password
3. You'll be redirected to the admin dashboard automatically

**Can't log in?**
- Check that your account is active (contact your system administrator)
- Use the "Forgot Password?" link if you've forgotten your password
- Make sure you're using the email address your account was created with

## 2. Understanding the Dashboard

The dashboard is your command center. It answers three questions:

### What is happening?
The top row shows KPI cards: Total Students, Active Applications, Revenue, Visa cases, and more. Each card is clickable — tap it to see the underlying records.

### What needs attention?
The **Action Required** section (amber banner) shows items that need your immediate action:
- **Overdue tasks** — tasks past their due date
- **Documents need review** — uploaded documents waiting for approval
- **Outstanding payments** — unpaid invoice amounts

Each item links directly to the relevant page.

### What should I do next?
The **Quick Actions** bar gives you one-click access to the most common tasks:
- Add Student
- Add Lead
- Create Application
- Review Documents
- Record Payment
- Create Invoice
- Create Task

## 3. Adding Your First Student

1. Click **Add Student** in Quick Actions (or go to **CRM → Students**)
2. Fill in the student's personal information (name, email, phone)
3. Add academic information (education level, institution)
4. Add passport information if available
5. Click **Save**

The student is now in the system and you can create applications for them.

## 4. Creating an Application

1. Go to **CRM → Applications**
2. Click **Create Application**
3. Select the student
4. Select the country, university, course, and intake
5. The application starts at the **Lead** stage
6. As the student progresses, advance the stage through the pipeline

The application pipeline has 18 stages, from Lead to Completed. Each stage change is recorded in the timeline.

## 5. Managing Documents

1. Go to **Documents & Visa → Document Review**
2. You'll see all documents that need attention
3. Click a document to review it
4. **Approve** if the document is correct
5. **Reject** with a reason if the document has issues — the student will be notified to re-upload

Document statuses:
- **Requested** — the counselor asked the student for this document
- **Uploaded** — the student uploaded it, waiting for review
- **Under Review** — a counselor is reviewing it
- **Approved** — the document is verified and accepted
- **Rejected** — the document was rejected, student needs to re-upload

## 6. Recording a Payment

1. Go to **Finance → Payments**
2. Click **Record Payment**
3. Select the student
4. Enter the amount, payment method, and reference number
5. The payment is linked to the student's invoices automatically

## 7. Using Global Search

Press **Ctrl+K** (or **Cmd+K** on Mac) anywhere in the admin panel to search across:
- Students
- Leads
- Applications
- Employees
- Universities
- Courses
- Payments
- Invoices
- Tasks
- Appointments

Results are grouped by type — just click any result to go to its detail page.

## 8. Checking Reports

Go to **Finance → Reports** to see:
- Student reports
- Application reports
- Visa reports
- Financial reports
- Employee performance

Use the filters to narrow down by date range, branch, or employee. Click **Export** to download a CSV file.
