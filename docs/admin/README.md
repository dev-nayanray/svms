## Who Should Use This

- **Office managers** managing day-to-day operations
- **Branch managers** overseeing multiple counselors
- **Business administrators** responsible for students, applications, and finance
- **System administrators** managing users, roles, and settings

## Key Principles

1. **Nothing is permanently deleted** — records are archived (soft-deleted), preserving history
2. **Every important action is logged** — the audit trail shows who did what and when
3. **The dashboard tells you what needs attention** — check it first every morning
4. **Search is everywhere** — press Ctrl+K (or Cmd+K) to search across students, leads, applications, and more
5. **Statuses use plain English** — "Under Review" not "UNDER_REVIEW"
