# Business Workflow — The Euroscope Student Journey

This document explains the complete journey a student takes through the Euroscope system, from initial inquiry to visa decision and travel.

## The Complete Journey

```
Lead → Counselling → Student Registration → Profile Assessment → Country Selection → University Selection → Course Selection → Document Collection → University Application → Offer Letter → Deposit Payment → Visa Preparation → Visa Submission → Biometrics → Interview → Visa Decision → Travel Preparation → Completed
```

## Stage-by-Stage Guide

### 1. Lead
**What happens:** A prospective student inquires via the website, phone, or walk-in.

**What the admin does:**
- Create a lead in **CRM → Leads**
- Record their name, contact info, and what they're interested in
- Assign the lead to a counselor
- Set the lead status to **New**

### 2. Counselling
**What happens:** The assigned counselor contacts the lead to understand their goals.

**What the admin does:**
- Change lead status to **Contacted**
- Schedule a counselling appointment
- After the session, change status to **Counselling**

### 3. Student Registration
**What happens:** The lead decides to proceed and becomes a registered student.

**What the admin does:**
- Convert the lead to a student using the **Convert** button
- The lead's contact info carries over to the new student profile
- The lead status changes to **Converted**

### 4. Profile Assessment
**What happens:** The counselor assesses the student's academic background and English proficiency.

**What the admin does:**
- Go to the Student 360 page
- Add academic records (SSC, HSC, Bachelor's, etc.)
- Add English proficiency test scores (IELTS, TOEFL, etc.)
- Create an application and set the stage to **Profile Assessment**

### 5. Country Selection
**What happens:** The student and counselor decide which country to apply to.

**What the admin does:**
- Browse **Academic Catalog → Countries** for available destinations
- Set the application's country

### 6. University Selection
**What happens:** The student shortlists universities.

**What the admin does:**
- Browse **Academic Catalog → Universities** for options
- Set the application's university
- Students can also browse universities themselves in the Student Portal

### 7. Course Selection
**What happens:** A specific course is chosen.

**What the admin does:**
- Browse **Academic Catalog → Courses** for options
- Set the application's course

### 8. Document Collection
**What happens:** Required documents are collected from the student.

**What the admin does:**
- Go to the application's Documents tab
- Request required documents (passport, transcripts, IELTS certificate, etc.)
- Students upload documents via the Student Portal
- Review uploaded documents in **Documents & Visa → Document Review**
- Approve or reject each document

### 9. University Application
**What happens:** The application is submitted to the university.

**What the admin does:**
- Advance the application stage to **Application Submitted**
- Record the submission date

### 10. Offer Letter
**What happens:** The university sends an offer (conditional or unconditional).

**What the admin does:**
- Advance the stage to **Conditional Offer** or **Unconditional Offer**
- Upload the offer letter as a document

### 11. Deposit Payment
**What happens:** The student pays the university deposit.

**What the admin does:**
- Create an invoice in **Finance → Invoices**
- Record the payment in **Finance → Payments**
- Advance the stage to **Confirmation**

### 12. Visa Preparation
**What happens:** The student prepares visa documents.

**What the admin does:**
- Advance the stage to **Visa Preparation**
- Ensure all visa-required documents are collected and approved
- Check visa requirements in **Documents & Visa → Visa Management**

### 13. Visa Submission
**What happens:** The visa application is submitted to the embassy.

**What the admin does:**
- Advance the stage to **Visa Submitted**
- Record the visa application in the Visa Management module

### 14. Biometrics
**What happens:** The student attends biometrics appointment.

**What the admin does:**
- Update the visa record with the biometrics date
- Advance the stage to **Biometrics**

### 15. Interview
**What happens:** The student attends a visa interview (if required).

**What the admin does:**
- Update the visa record with the interview date
- Advance the stage to **Interview**

### 16. Visa Decision
**What happens:** The visa is approved or refused.

**What the admin does:**
- If approved: advance to **Visa Decision** (approved)
- If refused: record the refusal reason, update status

### 17. Travel Preparation
**What happens:** The student prepares for travel.

**What the admin does:**
- Advance the stage to **Travel Preparation**
- Help with flight booking, accommodation, etc.

### 18. Completed
**What happens:** The student has traveled and the journey is complete.

**What the admin does:**
- Advance the stage to **Completed**
- The application status changes to **Completed**

## Important Notes

- **Every stage change is logged** in the application timeline
- **Invalid transitions are prevented** — you can't skip required stages
- **Documents must be approved** before advancing past Document Collection
- **Payments must be recorded** before advancing past Deposit Payment
- **The student is notified** of important stage changes automatically
